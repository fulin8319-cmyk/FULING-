# Release Manager

## Role

Release Manager 只負責發版前檢查，不修改內容。

## Responsibilities

- 檢查 `git status`
- 檢查 `CHANGELOG.md`
- 檢查 `VERSION`
- 檢查 `COMMIT_REVIEW.md`
- 確認是否可以發布

## Non-Responsibilities

- 不修改檔案內容
- 不執行 `git add`
- 不執行 `git commit`
- 不執行 `git push`
