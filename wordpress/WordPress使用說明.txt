【如何在WordPress中使用】
═══════════════════════════════════════════════════════════════

方案 A：快速貼上（推薦新手）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1️⃣ 登入你的WordPress後台
   進入 頁面 → 新增頁面

2️⃣ 複製 WP_01_FAQ頁面_WordPress版.txt 全部內容
   • 打開該txt文檔
   • Ctrl+A 全選
   • Ctrl+C 複製

3️⃣ 在WordPress編輯器中：
   • 點擊「 + 」 新增「HTML」區塊（不是文字區塊）
   • 或切換到「 文本 」模式（Tab鍵旁邊）
   • 貼上內容（Ctrl+V）

4️⃣ 設定頁面資訊：
   頁面標題：常見問題（或自訂）
   永久連結：/faq/ 或 /常見問題/
   發佈

5️⃣ 重複步驟 2-4，用 WP_02_產品頁... 文件
   建立產品頁面


方案 B：分拆為獨立頁面（推薦整齊）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

WP_02_產品頁 中有 6 個產品，建議：

頁面 1：數位印花專用布（總覽）
頁面 2：單面PK布
頁面 3：細針鳥眼布
頁面 4：75D雙面布
頁面 5：大目鳥眼布
頁面 6：PK健康布

每個頁面：
• 複製該產品的內容區塊（<!-- ========== 產品 X ... ========== --> 之間）
• 新增頁面 → 文本模式 → 貼上
• 設定標題和連結


方案 C：使用古騰堡區塊編輯器（WordPress 5.0+）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1️⃣ 新增頁面
2️⃣ 點擊「 + 」按鈕
3️⃣ 搜尋並選擇「自訂HTML」區塊
4️⃣ 貼上內容
5️⃣ 發佈

【重要提醒】
═══════════════════════════════════════════════════════════════

✓ 樣式問題？
  如果頁面樣式看起來不對，可能是 CSS 被你的主題覆蓋。
  解決方案：
  • 進入 外觀 → 自訂 → 額外CSS
  • 將下面的 CSS 複製貼上：

---
.product-container, .faq-container {
    max-width: 1000px;
    margin: 0 auto;
    padding: 40px 20px;
}
.product-h1, .faq-title {
    color: #222;
    margin-bottom: 15px;
}
.spec-table { width: 100%; border-collapse: collapse; }
.spec-table th { background: #007bff; color: white; padding: 12px; }
.spec-table td { padding: 12px; border-bottom: 1px solid #e0e0e0; }
.product-highlights {
    display: grid;
    grid-template-columns: repeat(auto-fit, minmax(220px, 1fr));
    gap: 20px;
    margin-bottom: 50px;
}
---

✓ Schema Markup 問題？
  FAQ頁面包含了 Schema Markup（用於Google搜尋結果）。
  如果你的主題已有 Schema Markup 外掛，可以移除重複的。
  否則保留即可。

✓ 按鈕不工作？
  href 中的 tel: 和 https:// 應該自動工作。
  如果不工作，可能是：
  • 主題CSS干擾，改用按鈕區塊代替
  • 或改為純文字連結

【進階設置】
═══════════════════════════════════════════════════════════════

1. 新增到導航菜單
   進入 外觀 → 菜單 → 編輯
   新增你剛建立的「FAQ」和「產品」頁面到菜單

2. 設定為首頁下的子頁面
   編輯頁面 → 頁面屬性 → 父頁面
   選擇「首頁」或「產品」作為父頁面

3. 修改永久連結結構
   設定 → 永久連結
   選擇「文章名稱」會更乾淨

4. 新增特色圖片（可選）
   編輯頁面 → 設定側邊欄 → 特色圖片
   上傳布料圖片

【常見問題】
═══════════════════════════════════════════════════════════════

Q：能否只貼上文字部分，去掉樣式？
A：可以。只複製 <div class="faq-container"> 到 </div> 之間
   的純文本內容（不含 <style> 標籤）。但會失去格式，
   建議貼上完整版本。

Q：多個頁面會很複雜嗎？
A：不會。每個都是獨立頁面，管理很簡單。
   WordPress會自動排序。

Q：能編輯FAQ或產品內容嗎？
A：當然。貼上後，在WordPress編輯器中直接修改。
   你可以新增、刪除或重排FAQ項目。

Q：圖片怎麼加？
A：在WordPress編輯器中，在你想加圖片的地方：
   • 點擊 + → 圖片
   • 上傳布料照片
