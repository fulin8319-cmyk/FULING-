# Grok Script

## Topic

Discontinued fabric short video.

## Script Direction

- Open with a clear hook: why this fabric was discontinued
- Explain the key traits in simple language
- Connect the fabric to practical use cases
- End with a concise takeaway for inventory or content reuse

## Draft Beat

1. Hook
2. Fabric background
3. Main features
4. Why it matters
5. Closing line

## Notes

- Keep the tone practical
- Avoid overpromising availability
- Focus on knowledge value and reuse value
